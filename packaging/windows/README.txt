Portable Ops Native / Portable Ops+ Native — Windows x64

Extract the whole ZIP before launching PortableOpsNative.exe or
PortableOpsPlusNative.exe. Keep the DLLs, overlays/, fonts/ and licenses/
beside the program. No compiler or development tools are needed.

First launch opens setup and asks for your own disc image:
  Portable Ops:  North America, ULUS-10202, version 1.02
  Portable Ops+: North America, ULUS-10290, version 1.01
Setup validates the image, prepares game data and starts the game.
If you choose to use the ISO in place, keep it at that location.
Later launches start the game directly. Launch with --install to reopen setup.

Data, settings and saves normally live under:
  %APPDATA%\PortableOpsNative\ULUS10202\
  %APPDATA%\PortableOpsPlusNative\ULUS10290\
Replacing the extracted program folder preserves those files.

Requires 64-bit Windows 10 or newer and a working Vulkan graphics driver.
Install current graphics drivers from your GPU vendor if Vulkan is missing.
Do not download individual DLLs from third-party DLL sites.

Native game code is included; disc images and PSP executables are not.
Online play is incomplete: finding and joining other players' games does
not yet work. See licenses/ for third-party software notices.
